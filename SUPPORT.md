# Support

## Getting help

Support for YorNaaS is provided through [GitHub issues](https://github.com/ravidorr/yes-or-no-as-a-service/issues).

Use issues for:

- bug reports
- questions about setup, tests, or development
- feature requests
- documentation improvements

## Before opening an issue

1. Check existing open and closed issues for a duplicate.
2. Include your Node.js version (`node --version`).
3. Include steps to reproduce the problem.
4. Include expected behavior and actual behavior.

## Response expectations

This is a small open source project maintained in spare time. Issues are handled on a best-effort basis with no guaranteed response time or SLA.

## Security reports

Do not use public issues for security vulnerabilities. See [SECURITY.md](SECURITY.md).

## Contributing fixes

If you want to contribute a fix, see [CONTRIBUTING.md](CONTRIBUTING.md).

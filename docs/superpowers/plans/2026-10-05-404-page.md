# 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the specified, theme-aware 404 document with HTTP 404 status for every unmatched request.

**Architecture:** Extract the existing theme-toggle implementation into a small browser module shared by answer pages and the standalone 404 document. Read `public/404.html` at application construction and send it from Express's final fallback middleware with the existing status code. Keep answer rendering and API endpoints unchanged.

**Tech Stack:** Node.js 22, Express 5, vanilla HTML/CSS/ES modules, node:test, Playwright.

## Global Constraints

- No new dependencies.
- Unknown paths, unknown API routes, and unmatched non-GET methods return the HTML page with HTTP 404.
- The 404 document uses `body[data-mode="404"]`, the existing tokenized stylesheet, and the same persistent light/dark toggle.
- Keep the 404 copy and links exactly as defined in `SPEC.md`.
- Use `localThis` for any newly written Jest-style unit-test state.

- [ ] **Step 3: Implement the shared initializer**

```js
const MOON_SVG =
  '<svg viewBox="0 0 24 24" aria-hidden="true"><path d="M12 3a6 6 0 0 0 9 9 9 9 0 1 1-9-9Z"/></svg>';
const SUN_SVG =
  '<svg viewBox="0 0 24 24" aria-hidden="true"><circle cx="12" cy="12" r="4"/><path d="M12 2v2M12 20v2M4.93 4.93l1.41 1.41M17.66 17.66l1.41 1.41M2 12h2M20 12h2M4.93 19.07l1.41-1.41M17.66 6.34l1.41-1.41"/></svg>';

export function initializeThemeToggle({
  document = globalThis.document,
  matchMedia = globalThis.matchMedia.bind(globalThis),
  storage = globalThis.localStorage
} = {}) {
  const toggle = document.querySelector('#theme-toggle');
  const getEffectiveTheme = () =>
    document.documentElement.dataset.theme ||
    (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
  const render = (theme) => {
    toggle.innerHTML = theme === 'dark' ? SUN_SVG : MOON_SVG;
    toggle.setAttribute('aria-label', `Switch to ${theme === 'dark' ? 'light' : 'dark'} theme`);
  };

  render(getEffectiveTheme());
  toggle.addEventListener('click', () => {
    const theme = getEffectiveTheme() === 'dark' ? 'light' : 'dark';
    document.documentElement.dataset.theme = theme;
    try { storage.setItem('theme', theme); } catch {}
    render(theme);
  });
}
```

Remove the equivalent constants and functions from `public/app.js`; import and call `initializeThemeToggle()` after page copy initialization.
